# Redrawing the Map: interactive edition

Interactive web edition of GRAMA's policy note *Redrawing the Map: A Policy Note on Panchayat Delimitation in Bihar* (September 2026).

- `index.html` – the report page
- `report.js` – chart cards
- `data.js` – summary values used to draw the charts
- `assets/` – photographs and the data-stack infographic
